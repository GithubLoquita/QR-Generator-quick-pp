Local Testing & Vercel Deployment

100% Free HTML, CSS and JavaScript tool

Zero Server or Paid API Needed
This tool builds directly to static assets (HTML/CSS/JS). Host it on Vercel at $0 forever with custom domain support.

Option A: Deploy via Vercel CLI (1-Minute)

$ npm install -g vercel
$ vercel
$ vercel --prod

Option B: Git Push to GitHub & Connect Vercel

  1. Push repository to your GitHub account: git push origin main
  2. Visit vercel.com, sign in, and click Add New Project.
  3. Select the repository. Framework preset is automatically detected as Vite.
  4. Click Deploy. Live URL with free SSL is generated immediately!

Run these commands on your computer to test locally:

1. Install dependencies:
$ npm install
2. Run local development server:
$ npm run dev

Opens at http://localhost:3000

3. Build for production:
$ npm run build
