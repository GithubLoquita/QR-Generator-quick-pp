Privacy Policy

QR Studio ("we", "us", or "our"), developed by ANIX Software Technology, is committed to transparency. This Privacy Policy details exactly how your information, uploaded files, and technical data are handled when using our browser tools.

1 What Information We Collect and Why

We operate on a data-minimization principle:

  • No Account Information: We do not ask for, create, or store user accounts, logins, passwords, or personal profiles.
  • No Payment Details: The service is 100% free; we never request credit cards, bank accounts, or billing information.
  • Visitor Count Telemetry: To display an anonymous live visit counter, the application connects to a public counting endpoint (countapi.mileshilliard.com). This request transmits standard HTTP request headers without collecting or recording your personal name or phone number.
  • Correspondence Data: If you voluntarily email us at hembramgroupofficials@gmail.com, we retain your email address and message contents solely to answer your inquiry or address your grievance.

2 Local In-Browser Processing (Verified Technical Reality)

We have architected QR Studio so that all core computation occurs locally inside your web browser engine:

QR Codes: Generated client-side using JavaScript Canvas and SVG manipulation (qr-code-styling).

Barcodes: Rendered directly into DOM SVG elements using client-side mathematical algorithms (JsBarcode).

Image to PDF: Selected images are read via the browser's native FileReader API into temporary memory (Blob/DataURL) and compiled into PDF binary format using jsPDF locally.

Merge PDF: Input PDF files are loaded as in-memory ArrayBuffer objects and merged via pdf-lib inside your device's memory.

3 No Remote Transmission of User Files

Your document files, pictures, generated QR payloads (such as private Wi-Fi passwords, contact phone numbers, or WhatsApp messages), and PDF files are never uploaded, mirrored, or transmitted to any server operated by ANIX Software Technology or any remote conversion API. You can independently verify this at any time by inspecting the browser's Network Developer Tools (F12 → Network) while processing files.

4 Hosting Provider Logs & Browser Storage

While we operate no custom backend server, the website is hosted on Vercel Inc. edge infrastructure:

  • Edge Access Logs: Like virtually all hosting providers, Vercel automatically logs HTTP request headers, client IP addresses, requesting URL, user-agent string, and timestamps for system stability, DDoS mitigation, and operational metrics. These logs are managed under Vercel's Privacy Policy.
  • Local Storage (localStorage): We use client-side keys purely to save your local UI preferences:
    • qr_studio_terms_consent: Stores your accepted terms version and timestamp.
    • qr_studio_file_upload_consent: Stores your acknowledgment of file ownership rights.
    • qr_studio_last_known_count: Stores cached visitor count locally for smooth rendering.

5 File Retention and Instant Deletion

Because files remain solely in your web browser's volatile memory (RAM), there is zero server-side retention. When you close the browser tab, click "Clear All", or navigate away, the browser immediately releases the allocated memory and the files are discarded.

6 Security Limitations & Vulnerability Reporting

While we apply strict client-side isolation, no internet service can guarantee 100% absolute security:

  • Your device environment (such as malicious third-party browser extensions, unpatched operating systems, or screen-recording software) may potentially inspect DOM contents.
  • We encourage users not to process sensitive unredacted government identification documents or highly confidential credentials on shared public computers.
  • Reporting a Vulnerability or Data Concern: If you identify a potential security flaw or unintended network leak, please report it immediately to our dedicated response email: hembramgroupofficials@gmail.com.

Our website utilizes the following external resources:

  • Google Fonts: Loads the "Plus Jakarta Sans" and "JetBrains Mono" typography. Google may log your IP address to deliver font assets in accordance with their privacy policy.
  • CountAPI Service: Anonymous incrementing counter for public site metrics.

8 Children's Privacy Protection

QR Studio does not knowingly collect, request, or solicit personal identification information from children under the age of 18 years (or under 13 in relevant jurisdictions). Because all generation and conversion activities are client-side, we possess no database of child data. If a parent or guardian believes their child has submitted personal information via email correspondence, please contact us for immediate deletion.
